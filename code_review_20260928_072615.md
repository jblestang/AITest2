## 1. Domain & Architectural Overview

The DFDL/DPath expression subsystem forms the core expression parser and evaluator for Apache Daffodil TDML compliance. It parses XPath / DPath expression strings in element properties (`dfdl:occursCount`, `dfdl:inputValueCalc`, `dfdl:outputValueCalc`, discriminator expressions, etc.) into a canonical AST and evaluates them over the infoset data tree.

### Core Architecture (`dfdl_vm::expression`):
- [`grammar.pest`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/grammar.pest): Pest PEG DPath grammar defining literals, QNames, relative/root/parent paths, function calls, unary/binary ops, and cast expressions.
- [`ast.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/ast.rs): Canonical AST node types (`Expr`, `FuncKind`, `BinaryOpKind`, `UnaryOpKind`, `SimpleType`).
- [`path.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/path.rs): Canonical `Path`, `PathOrigin`, `StepTest`, and `PathStep` abstractions with full `fmt::Display` formatting.
- [`parser.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/parser.rs): High-efficiency Pest pair parser converting string expressions directly into AST `Expr` nodes.
- [`context.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/context.rs): `EvalContext` trait abstracting infoset node navigation, sibling state lookups, variables, and value length computations.
- [`eval.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/eval.rs): Unified expression evaluator executing AST evaluation against any context implementing `EvalContext`.
- [`error.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/expression/error.rs): `ExpressionError` taxonomy.
