## Key Improvements & Compliance Fixes

### 1. Discriminator Type-Cast Expression Stripping
- **File:** [`src/vm/decoder.rs`](file:///Users/jean-baptiste/Documents/AITest2/dfdl-vm/src/vm/decoder.rs#L350-L390)
- **Problem:** Discriminator expressions such as `{ xs:int(../../ex:trigger) eq 12 }` were rejected by the static equality fast path due to containing function calls (`xs:int(...)`), causing choice alternatives to fail erroneously.
- **Solution:** Introduced `Self::strip_type_cast_wrapper` to peel XML Schema / DFDL type constructor wrappers (`xs:*`, `xsd:*`, `dfdl:*`) from equality expressions before relative path navigation (`../`) and symbol resolution.

### 2. Choice Branch Error Message Format Normalization

- **Solution:** Cleaned up choice alternative failure messages when `Delimiter not found` is present, aligning error output with Daffodil expected strings.
