## 1. Domain & Architecture Analysis

### A. Property Parsing (`dfdl-vm/src/schema/parser/props.rs`)
- **Issue:** When parsing `occursCount`, integer numeric string literals (e.g. `occursCount="2"`) were setting `props.occurs_count_kind = Some(OccursCountKind::Expression)`. On fixed/scalar elements without array dimensions (`maxOccurs=1`), this caused the VM to attempt evaluating runtime XPath expressions on literal numbers, raising false `Expression Evaluation Error`s (observed in Section 05 `AK000`/`AK001` and Section 17 `AR000`).
- **Fix:** In `props.rs`, `props.occurs_count_expr` is set when parsing `occursCount`, but `occurs_count_kind` is left unset unless explicitly specified or required.
- **Safety / Development Assessment:** Avoids mutating state when property interpretation is context-dependent. Preserves scalar particle handling while supporting explicit array particle expression evaluation.

### B. Dynamic Expression Evaluation (`dfdl-vm/src/vm/decoder/particle.rs` & `xpath.rs`)
- **Issue:** Expression evaluation for `occursCount` was firing on scalar elements whose `occurs_max == Some(1)` even when no explicit `occursCount` expression was defined.
- **Fix:** Added guard checks in `particle.rs` to evaluate `occursCount` expressions only when `occurs_count_expr.is_some()` or when array bounds warrant explicit count calculation.
- **XPath Evaluation (`xpath.rs`):** Enabled simple integer literal parsing in `eval_occurs_count_xpath_expr` and added path step validation for variable references (`$var`) in multi-step paths to ensure correct scope resolution.

### C. XML Node Sibling Lookup (`dfdl-vm/src/xml_util.rs`)
- **Issue:** `local_name_str` was returning array index numbers (e.g. `"0"`) for stored element key strings with `|0` suffixes. This prevented ancestor element lookups when resolving element names across nested default namespaces (observed in Section 06 `defaultNamespaceInExpression`).
- **Fix:** Stripped array index suffixes before extracting the local name in `local_name_str`.
- **Safety Assessment:** Pure function enhancement, thread-safe, no side effects on XML structure.

### D. Delimiter Validation (`dfdl-vm/src/schema_validate/delimiters.rs`)
- **Issue:** A string matching check in delimiter validation had a slightly altered error message substring, causing Section 00 tests expecting `"The escape character cannot be the same as terminating markup for dfdl:separator or dfdl:terminator."` to fail.
- **Fix:** Restored exact target error message string.
