## 2. Review of Technical Changes & Domain Expertise

### 2.1 Resolution of Anonymous / Inline Simple Types in Representation Validation (`src/schema_validate/delimiters.rs`)
- **Root Cause:** `validate_representation_length_units` evaluated `is_string` by directly checking if `type_name.as_str() == "xs:string"`. Anonymous / inline simple types (e.g., `<xs:element name="string"><xs:simpleType><xs:restriction base="xs:string">`) assign synthetic type names like `__anon_1`.
- **Domain Impact:** Because `is_string` failed to recognize `__anon_1` as deriving from `BuiltinType::String`, the representation fell back to `schema.format_defaults.props.representation` (`binary`). When `lengthUnits="characters"` was set on the element, schema validation threw a false-positive `Schema Definition Error: Property lengthUnits cannot be 'characters' when representation is 'binary'`.
- **Surgical Fix:** Updated `effective_rep_and_lu` to use `schema.builtin_for_simple_base(&base)` via `schema.resolve_type(tn)`, correctly identifying all inline and derived simple string types.
- **Verification:** 65 previously blocked test cases in `Aligned_Data.tdml` instantly passed at compile and runtime.

### 2.2 Scoped Format Resolution and Included Document Merging (`src/schema/resolver.rs`, `src/schema/parser/document.rs`)
- **Root Cause:** Schema includes (e.g., `DFDLGeneralFormat.dfdl.xsd`) inside imported namespaces caused format collisions or infinite recursion when resolving QNames across namespaces.
- **Surgical Fix:**
  - Added `active_imports: BTreeSet<String>` to track import cycles safely while permitting sub-includes.
  - Preserved namespace qualifiers in format keys during document merging.
  - Added single-matching fallback logic in `lookup_named_format_in_document`.
- **Verification:** Section 06 (`simpleImport`, `importWithOverlappingNSPrefixes1`, `importWithOverlappingNSPrefixes2`, `long_chain_01`..`05`) and Section 08 property scoping cases resolved completely.

### 2.3 Collision Detection Logic for DFDL Properties (`src/schema/ast/mod.rs`)
- **Root Cause:** Format property collision checking falsely flagged non-colliding statement annotations (`<dfdl:discriminator>` / `<dfdl:assert>`).
- **Surgical Fix:** Implemented `has_property_collision(&self, other: &Self)` to specifically inspect format property fields.
- **Verification:** Avoided false compilation failures on valid annotations.
