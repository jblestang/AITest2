## 1. Summary of Migrated Expression Subsystems

All targeted hand-written string parsers have been fully migrated to the Pest PEG AST parser (`dfdl_vm::expression::parse_expression`):

2. **Length & occursCount Parsers**:

3. **Conditional Control Flow (`byteOrder`)**:
   - Refactored `parse_byte_order_if_expr` to inspect `Expr::IfThenElse { cond, then_branch, else_branch }` AST nodes.

4. **Assert & Discriminator Test Parsers**:
