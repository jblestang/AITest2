## 1. Summary of Changes

This code review documents fixes applied to Section 07 (Discriminators & Variables) compliance failures in `dfdl-vm` without introducing regressions in other test sections.

### Key Modifications

1. **Structured Point of Uncertainty (POU) Stack Representation (`src/vm/decoder/mod.rs`)**
   - Introduced `PouKind` (`Choice` vs `Occurrence`) and `PouFrame` struct (`kind`, `committed`).
   - Updated `commit_nearest_undiscriminated_pou()`: when a discriminator evaluates to `true`, it now commits all active `Occurrence` frames and the nearest enclosing `Choice` frame on the stack.
   - **Rationale:** According to DFDL Spec Section 7.4, a discriminator resolving within a choice branch commits both the occurrence loop and the enclosing choice branch, preventing incorrect backtracking to sibling choice branches when an inner element or discriminator fails.

2. **Choice Branch Pre-Validation Error Escalation (`src/vm/decoder/choice.rs`)**
   - Added SDE/RSDE check in `decode_choice`: if `choice_branch_discriminator_matches_with_reason` returns a Schema Definition Error or Runtime Schema Definition Error, decoding halts immediately and returns the error without backtracking.
   - **Rationale:** Assert failures attempting to evaluate non-existent elements raise an RSDE which must not be swallowed by choice backtracking.

3. **Prefixed Schema Context in Simple Element Decode Failures (`src/vm/decoder/element.rs`)**
   - Formatted simple element decode failure messages with `element_prefixed_name` (`Schema context: ex:{name}`).
   - **Rationale:** Ensures exact line matching against TDML expected error lists in Daffodil compliance test suites.

4. **Dynamic XPath Expressions in Terminators (`src/vm/runtime/delimited.rs`, `numeric_text_parse.rs`, `xpath.rs`)**
   - Passed `scan_ctx` into `consume_text_field_terminator_after_fixed_length` to resolve dynamic expressions (e.g. `dfdl:terminator="{ /ex:elem/ex:header/ex:term }"`) from `resolved_stop_delimiters`.
   - Updated `sibling_state_by_local` in `xpath.rs` to strip prefixes before comparing QName local-names.

5. **CI Gate Threshold Updates (`tests/scan_sections.rs`)**
   - Updated `daffodil_section07_regression_gate` pass minimum from 275 to 290 and max failures from 28 to 13.
   - Updated `daffodil_section16_regression_gate` to (72, 15).
   - Confirmed 100% green execution across all 19 section regression gates in `scan_sections.rs`.
