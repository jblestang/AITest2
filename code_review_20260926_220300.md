## 2. Multi-Domain Code Review Findings

### 2.1 Software Development & Architecture Domain Review
- **Property Propagation & Inheritance (`src/ir/builder/props.rs`, `src/ir/builder/mod.rs`):**
  - **Finding:** Previously, `element_props_for_complex_content` omitted `format_ref` and `representation` from `DfdlProps` when constructing inherited properties for complex type children. This broke property scoping when root or intermediate complex elements specified `dfdl:ref="format_01"`.
  - **Resolution:** Added `format_ref` and `representation` fields to `element_props_for_complex_content` and updated `merge_dfdl_props` to set `base.representation_defined = true`. Additionally, moved `representation_defined` validation in `merge_props_full` after `merge_dfdl_props` resolves all format references.
  - **Assessment:** Clean separation of concern and accurate property propagation hierarchy matching DFDL specification rules.

- **Manual vs Automatic Alignment Handling (`src/schema/parser/props.rs`, `src/ir/builder/props.rs`):**
  - **Finding:** `dfdlx:alignmentKind="manual"` was not parsed into AST/IR properties, causing `dfdl:alignment="8"` on elements to force pre-alignment even when alignment was set to manual.
  - **Resolution:** Added `alignment_manual` field to `DfdlProps` and `IrProps`. When `alignment_manual` is active, `alignment` is forced to `1` (no pre-alignment), allowing mandatory text encoding 8-bit alignment validation checks (`start_bit_index % 8 != 0`) to accurately fail on misaligned text data as required.
  - **Assessment:** Correctly implements DFDL extension property semantics and alignment execution bounds.

### 2.2 DFDL & Signal/Format Parsing Domain Review
- **Bits-Charset Encoding & Delimited Stream Bounds (`src/vm/encoding.rs`, `src/vm/runtime/numeric_text_parse.rs`):**
  - **Finding:** Bits-charset encodings (e.g. ISO-8859-1 8-bit packed MSB/LSB first) require precise bit width tracking and byte alignment checks. 
  - **Resolution:** Corrected `X-DFDL-6-BIT-DFI-264-DUI-001` alphabet mapping, added 8-bit packed ISO-8859-1 charsets, and updated bit position reporting in parse errors to be 1-based (`start_bit_index + 1`) to align with standard TDML error expectations.
  - **Assessment:** Bit-stream alignment rules match DFDL encoding specification requirements.
